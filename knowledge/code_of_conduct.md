# Code of Conduct

## Purpose
This document outlines the standard operating procedure for Code of Conduct.

## Eligibility
All full-time employees are eligible for Code of Conduct subject to departmental approval.

## Step-by-step process
1. Initiate the Code of Conduct request via the employee portal.
2. Manager reviews and approves the request.
3. The relevant team processes the request.
4. Confirmation is sent to the employee.

## Expected timeline
The expected timeline for Code of Conduct is 3-5 business days.

## Escalation contact
For any issues regarding Code of Conduct, please contact the HR Helpdesk at hr@employeeclaw.com.

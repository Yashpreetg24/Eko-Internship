# EmployeeClaw

**EmployeeClaw** is an Autonomous Employee Onboarding AI Agent designed to streamline the HR onboarding process.

## Tech Stack
- **Frontend**: React + Tailwind CSS
- **Backend**: FastAPI
- **Agent**: LangGraph
- **Retrieval**: FAISS
- **Database**: SQLite + SQLAlchemy
- **Embeddings**: Sentence Transformers

## Folders
- `frontend/`: React web app
- `backend/`: FastAPI server
- `agent/`: LangGraph agent workflow and tools
- `knowledge/`: HR SOP markdown files
- `vector_db/`: FAISS index storage
